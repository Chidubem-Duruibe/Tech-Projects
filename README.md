### 🏥 [HMI Hackathon — Asynchronous Telehealth Platform]

An asynchronous telehealth platform prototype developed during the **HMI Hackathon: "Coding Today for the Health of Tomorrow."** The project was designed to address limitations associated with traditional telehealth models that rely heavily on scheduled video appointments. The platform provides an interactive experience for patients and healthcare providers while exploring how technology can improve access to healthcare services.

The application includes patient and provider dashboards, an interactive body-pain map for symptom reporting, provider region selection using an interactive 3D globe, and drone delivery tracking with live GPS visualization for medication delivery.

- **Stack:** React, TypeScript, D3.js, TopoJSON, HTML/CSS, Google AI Studio
- **Focus:** Healthcare Technology, Application Development, Data Visualization, User Experience
- **Features:** Patient/doctor dashboards, interactive SVG body map, 3D geographic visualization, provider selection, and drone delivery tracking
- **Skills:** Frontend development, UI/UX design, interactive data visualization, API/technology integration, teamwork, and problem-solving
- **Project Type:** Hackathon / Team Project
